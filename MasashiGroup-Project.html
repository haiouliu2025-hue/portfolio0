01 / Overview

An upgraded identity needs a consistent rollout.

MUSASHI Group completed its visual identity system (VIS) upgrade in April and had already updated some packaging. This project carries the established identity into website imagery, printed materials, physical decorations and illuminated signage.

I will lead the menu-image update and oversee how the existing design guidelines are applied across these touchpoints. The focus is consistent implementation, more appetising menu presentation and a repeatable process that shops can maintain.

02 / Challenge

Shop uploads vary. The brand experience should remain consistent.

Images uploaded by different shops have uncontrolled quality. Variations in lighting, framing, colour and presentation can make the same menu feel inconsistent online. At the same time, the upgraded VIS needs to work across materials with very different production requirements.

The image-upgrade budget is limited. We have therefore decided to work with AI image service agencies, using chef-captured photographs as the source and a shared photography direction to standardise the results.

03 / My role

Connect creative direction with day-to-day implementation.

01

Menu-image direction and review

Review shop-submitted images, define the standard photographic style and refine a reusable prompt for the AI agencies. Check the returned images before they are approved for website use.

02

VIS application across materials

Apply the existing guidelines to printed menus and other print materials, physical decorations and illuminated signs. Check logo use, typography, colour and information hierarchy in each application.

03

Client-guided website updates

Work from the group’s website requirements, supplied images, menu information and background data to improve the visual presentation of the menu.

04 / AI-assisted image optimisation

One repeatable workflow, from kitchen photograph to approved menu image.

AI optimisation provides a practical way to improve image consistency within the available budget. The workflow starts with real dish photographs and uses a shared prompt to guide the agencies towards a standard photographic style.

01

Capture & upload

Chefs photograph the dishes and upload the source images to the website.

02

Review & brief

We check image quality and product information, then send selected photographs to the AI agencies.

03

Standardise the prompt

We refine a shared photography prompt, using the approved VIS and reference images to define the style.

04

AI optimisation

The agencies optimise the submitted images against the agreed direction and return them for review.

05

Approve & maintain

We check consistency and dish accuracy before website use, then reuse the brief and prompt for future updates.

The approved prompt, reference images and review criteria become a repeatable asset set. Future batches can follow the same process, helping maintain the visual system across shops.

05 / Photography standard

Define the style once, then apply it across the menu.

The agency brief should specify camera angle, crop, lighting, background, colour treatment, dish scale and export requirements. These choices will be refined against the existing guidelines and agreed with the group before becoming the standard.

Working prompt / To be refined

Optimise the supplied photograph of [dish name] for a MUSASHI online menu. Preserve the actual ingredients, portion size, garnish and plating. Apply [approved camera angle], [approved lighting], [approved background] and [approved crop], matching the approved reference image. Keep food colour natural and texture realistic. Do not add or remove food. Export at [required dimensions and format]. Flag missing visual information for review.

Review the result against the original photograph and confirmed dish information. Approve images only when they are both visually consistent and representative of the food customers will receive. If the source image cannot support a reliable result, request a new photograph.

06 / Website presentation

Make the menu more appetising and easier to browse.

The visual update will bring the improved image library and existing VIS into a coherent menu presentation across desktop and mobile. The aim is to strengthen engagement through clear food imagery and consistent information hierarchy.

Because my permissions do not include direct access to website analytics or underlying site data, the update depends on the group’s guidance and the images, information and background data they provide. Performance assessment will rely on client-supplied reporting. Improved engagement is an objective, not a measured result.

07 / Print & physical applications

Carry the same identity from the screen into the space.

The implementation scope also covers printed materials, physical decorations and illuminated signs. Each application should follow the existing brand guidelines while accounting for its material, viewing distance and production conditions.

08 / Next steps

Establish the standard, test a batch, then roll it out.

01

Agree the image direction

Confirm the VIS references, dish information, photography style, agency brief and file requirements with the group.

02

Pilot the AI workflow

Test a representative set of dishes, refine the prompt and review the results for fidelity and consistency before wider use.

03

Maintain the system

Keep approved references, prompts and asset versions together. Use the same review criteria for future shop submissions and check every print and physical application against the guidelines.

Project scope is based on the project owner’s briefing. The images are supplied references and mockups; they do not establish that all proposed work is complete. No website performance outcomes are claimed.
